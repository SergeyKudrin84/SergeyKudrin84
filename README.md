## Hi there 👋

С 2006 года работаю с «1С»: сопровождаю разнородные учётные системы («1С:БГУ», «1С:ЗКГУ», «1С:Университет», «1С:Отель» и др.), проектирую интеграции (HTTP-/WEB-сервисы, обмен через шины, обработка больших объёмов данных), руковожу командами. С 2025 года формирую профиль Java-разработчика: завершил курс «Java-разработчик» на «Яндекс Практикуме», сейчас ищу позицию Trainee / Junior Java-разработчика, чтобы применять полученные знания на реальных задачах.

На текущем месте работы достиг максимального уровня развития. Работа подразделения налажена, функционирует самостоятельно. Хочу продолжать развиваться, попробовать себя в роли java-разработчика, от 1с немного устал. Хочу именно создавать полезные продукты, чего сейчас не хватает на текущем месте из-за бюрократических особенностей.

Сильные стороны: формализация требований и контроль результата (не приступаю к задаче без понятного конечного состояния), анализ чужого кода, построение устойчивых решений, опыт управления и наставничества. Открыт к обучению
